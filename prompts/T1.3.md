# 任务 1.3 — 可直接粘贴给编程 Agent

请先阅读仓库根目录的 `AGENTS.md`、`TASKS.md` 和 `DESIGN.md` 中「一句话定位」「技术方案」「美术风格」，以及「升级卡池」。然后**只做任务 1.3**，做完即停，不要开始 1.4。

## 要做的事

灵气攒满就暂停，弹出三张符箓，选一张立刻生效并继续：

- 等级和距离下一级的灵气要在画面上能看出来，界面保持很少
- 先做 8 张属性符：伤害、攻速、范围、移速、拾取范围，以及同类的冲刺和吸入。每张有叠加上限。名字和说明用简体中文，写清数字
- 每局可「重画」1 次，换掉当前三张。不要做焚符、封印
- 前 3 次升级尽量在 60 秒内出现，之后的间隔拉长。经验曲线、卡牌数值和重画次数写成可调常量
- 鼠标点击和键盘 1 / 2 / 3 都能选。手机竖屏和横屏也能点。暂停时摇杆和冲刺不能发动
- 样式保持暗、低饱和，不要可爱或 Q 版

## 完成标准

一局里能升 2–3 级，每次选择后能感到变强。刷新页面不报错。完成后把 `TASKS.md` 里 1.3 的状态改成「待验收」，并在回复里写明如何启动、每张卡做什么。

## 不要做

死亡和结算、计时结束、完整卡池、合体、五行印、法宝、收服、菜单、Spring Boot、Three.js、2.5D。
