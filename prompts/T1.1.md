# 任务 1.1 — 可直接粘贴给编程 Agent

请先阅读仓库根目录的 `AGENTS.md`、`TASKS.md` 和 `DESIGN.md` 中「一句话定位」「技术方案」「美术风格」三节。然后**只做任务 1.1**，做完即停，不要开始 1.2。

## 要做的事

从零搭建《山海收妖录》的可运行前端：

- 使用 **Vite + Phaser 3 + TypeScript**
- `npm install` 后执行 `npm run dev`，用浏览器打开就能玩
- 游戏画布 **1280×720**，场景用暗色、低饱和背景（墨黑、低饱和石青/赭石即可），不要亮色卡通风
- 玩家先用色块或简单占位图，比例不要 Q 版
- **WASD 或方向键** 移动，另做一次 **冲刺**（短距离位移 + 冷却）
- 画面上只提示一句：「走位即可」
- 不要加菜单、注册、敌人、攻击、经验、升级或任何后端

## 完成标准

在本机浏览器打开后，角色能流畅移动和冲刺，刷新页面不报错。完成后把 `TASKS.md` 里 1.1 的状态改成「待验收」，并在回复里写明如何启动、如何操作。

## 不要做

敌人、自动攻击、升级选卡、五行、收服、Spring Boot、Three.js、2.5D、商业素材侵权。
