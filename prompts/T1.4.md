# 任务 1.4 — 可直接粘贴给编程 Agent

请先阅读仓库根目录的 `AGENTS.md`、`TASKS.md` 和 `DESIGN.md` 中「一句话定位」「技术方案」「美术风格」。然后**只做任务 1.4**，做完即停，不要开始 1.5。

## 要做的事

一局有时限，也有生命，结束就能马上再开：

- 计时 3 分钟。选符箓暂停时不计时。生命归零则提前结束
- 玩家有生命值。妖物碰到人按冷却扣血，并保持现有的受击闪烁。不要一帧扣光
- 守住和阵亡都弹出结算：一句结果、击杀数、「再来一局」。点按钮或按回车立刻重开，等级、符箓、灵气、生命、击杀、计时和走位都回到开局
- 时长、生命上限、接触伤害和冷却写在 `src/game/constants.ts`
- 画面文字用简体中文。结算层保持暗、低饱和。键盘、摇杆、冲刺和选符箓在结算之后、重开之后都还能用

## 完成标准

能打完一局并马上重开。输赢都有击杀数。刷新页面不报错。完成后把 `TASKS.md` 里 1.4 的状态改成「待验收」，并在回复里写明如何启动、怎么结束、怎么重开。

## 不要做

灵玉、存档、每日挑战、localStorage、后端、三种新小怪、伤害数字、五行、收服、菜单、Spring Boot、Three.js、2.5D。
