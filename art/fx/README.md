# 招摇之山的地面和攻击画面

这些图只换画面。扇面、冲刺斩、灵气的数值都没改。灵宠是狌狌。

| 画面 | 游戏里怎么用 | 没改的判定 |
| --- | --- | --- |
| 招摇之山 | `public/art/ground/zhaoyao.png`，1280×720，铺满画布 | 地图仍是这一张，没有镜头滚动。「招摇之山」四个字仍是单独的文字 |
| 藤鞭 | `public/art/fx/whip_vine.png`，藤根锚在狌狌身上，转到扇面中线，长度缩到半径，再按扇面裁开 | 张角 65 度、半径 220。长鞭每层加角度和半径。伤害、640 毫秒间隔、扫开时间都没变 |
| 冲刺斩 | `public/art/fx/dash_slash.png`，沿这次走过的路径旋转、拉长 | 带子半径 78、伤害 2、每只每次一刀、停留 180 毫秒 |
| 灵气 | `public/art/fx/lingqi_orb.png`，最近邻缩到直径 14 | 拾取半径 52，掉落和吸取规则没变 |

中间那片裂开的石板比四周的土更暗，深色妖物走上去会糊成一块。游戏里的这张只把那片石板提亮了一点，边角和整张图的暗调没抬。没改过的原图在 `art/ground/source/zhaoyao_ground.png`。

高清源图在 `art/fx/source/`，构建不会打进页面。以后改画面用源图，不要用缩过的那张。
