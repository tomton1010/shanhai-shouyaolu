# 道士与狌狌待机图

Tom 定稿的两张透明底待机图，接进招摇之山这一局，替换原来的色块。不要重绘、改色。以后做动作帧，用 `source/` 里的高清图，不要用游戏里缩过的那张。

灵宠是狌狌。

| 角色 | 原画朝向 | 画面边长 | 锚点 |
| --- | --- | --- | --- |
| 道士 | 略俯视，面朝右下。往左走时水平翻转 | 70px，身高约 64 | 躯干。袍摆不参与接触和拾取 |
| 狌狌 | 同样的镜头，面朝右下。往左走时水平翻转 | 70px，身高约 64 | 躯干。耳朵、毛发和手脚不参与接触和拾取 |

正上、正下约 20 度以内不翻面，避免贴着上下走时来回闪。同屏按最近邻缩放，不用线性过滤。

胸口还有一小块朱砂符，跟着冲刺冷却变色：能冲时是朱砂，冷却中变暗，冲刺那一下变浅。冲刺的距离、时长和冷却没有改。
